# Ayuub's HTML Portfolio

A small collection of front-end practice projects built with semantic HTML and simple, focused page layouts.

## Projects

- **Movie Ranking** — a curated movie-list page
- **Birthday Invite** — a themed invitation page
- **Swedish Colors** — a visual vocabulary page for Swedish colors
- **Motivation Meme** — a simple motivational poster page

## Run locally

Open `index.html` in a browser, or serve the folder with any local static-file server.

## Project structure

- `index.html` — portfolio index
- `public/` — individual project pages
- `assets/images/` — project screenshots and visual assets

This repository is an early web-development portfolio: small projects, clear structure, and visible progress.
